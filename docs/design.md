# 设计说明 (Design) — 多维宇宙档案馆

## 1. 页面结构

### 一级页面：主宇宙中枢首页
浏览顺序：导航栏 → Hero（标题+标语） → 世界入口卡片网格 → 宇宙公告 → 页脚

### 二级页面：独立小世界子页
- Hero 横幅区 → 模块标签栏 → 6 个内容模块（概览 / 法则 / 地域 / 人物 / 剧情 / 图库）→ 页脚

## 2. 视觉设计

### 配色方案
| 角色 | 色值 | 用途 |
|------|------|------|
| 深空黑 | #07070d | 主背景 |
| 深色卡片 | rgba(18,18,35,0.7) | 模块卡片背景 |
| 主文字 | #e8e8f0 | 正文标题 |
| 次要文字 | #9898b8 | 正文说明 |
| 强调蓝 | #4a8fe0 | 链接、高亮、装饰线 |
| 强调紫 | #7c5cbf | 渐变辅助色 |

### 字体
- 标题/英文展示：Orbitron（科幻感无衬线字体）
- 正文/中文：Noto Sans SC + Inter

### 整体风格
- 深色背景 + 半透明毛玻璃卡片
- 微弱的星空粒子动效
- 低饱和配色，高对比度文字
- 卡片悬浮上浮动效
- 渐变文字标题

## 3. 响应式要求

### 桌面端（>768px）
- 世界卡片 3 列网格布局
- 导航栏水平显示
- 信息卡片多列排列

### 手机端（≤768px）
- 卡片网格单列
- 导航链接折叠为汉堡菜单
- 模块标签可横向滚动

## 4. 文件映射

```
个人网站项目/
├─ index.html               ← 主宇宙中枢首页
├─ css/main.css             ← 全局样式
├─ js/main.js               ← 交互（星空、滚动、标签、菜单）
├─ worlds/
│  ├─ starlight-realm.html  ← 星落之境子页
│  ├─ rust-era.html         ← 铁锈纪原子页
│  └─ emerald-court.html    ← 翠梦庭阁子页
├─ docs/                    ← 项目文档
├─ report/                  ← 最终报告
└─ screenshots/             ← 截图证据
```

## 5. 模板保留与修改
- 未使用外部模板，从零构建的自定义页面
- 所有视觉元素为原创设计

## 6. 素材来源
- 无外部图片素材（使用 CSS 渐变作为背景占位）
- 图标使用 Unicode 字符
- 字体来源：Google Fonts (Orbitron, Inter, Noto Sans SC)
- 所有文字内容为原创生成
