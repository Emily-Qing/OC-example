# 产品需求文档 (PRD) — 多维宇宙档案馆

## 1. 项目定位

**项目名称**：多维宇宙档案馆（Multiverse Archive）

**一句话说明**：一个沉浸式的多平行世界世界观展示网站，以「翻阅宇宙卷宗」为核心理念，让访客在深色科幻感的界面中浏览独立平行小世界的完整设定。

## 2. 目标用户与场景

| 维度 | 说明 |
|------|------|
| 目标访问者 | 原创世界观爱好者、创作同好、潜在合作者、教师与同学 |
| 最先寻找的信息 | 世界观整体设定概览、可浏览的世界列表、每个世界的基础信息 |
| 期望访客记住 | 这是一个结构清晰、视觉沉浸的多世界宇宙集群，每个世界都有完整的独立设定 |

## 3. 本期范围

### 必须包含
- 主宇宙中枢首页（世界入口聚合地）
- 至少 3 个小世界子页面
- 每个小世界包含 6 个核心模块：世界概览、法则律法、地域势力、人物图鉴、主线剧情、世界图库
- 暗色科幻/奇幻视觉风格
- 桌面与移动端适配
- 导航系统：返回宇宙中枢 + 小世界内部模块切换

### 本期不做
- 用户登录/注册系统
- 数据库后端
- 内容编辑/创建功能（纯展示站）
- 访客追踪与数据分析
- 复杂交互框架

## 4. 成功标准

- 页面可正常访问，无死链接
- 所有模块内容填充完成，无占位文字
- 桌面端与移动端均可正常浏览，无布局溢出
- 导航功能正常：世界入口卡片可跳转，模块标签可切换
- GitHub Pages 部署后可公开访问

## 5. 隐私边界
- 不公开私人手机号、住址、身份证件
- 不包含 API Key 或密码
- 不包含课程邀请码
