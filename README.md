# 多维宇宙档案馆

一个沉浸式的多平行世界原创世界观展示网站。以「翻阅宇宙卷宗」为核心理念，构建了由主宇宙中枢和多个独立小世界组成的层级化展示体系。

## 所用模板

本项目未使用外部模板，所有页面与样式均为从零构建的自定义实现。

## 主要修改内容

- 构建了完整的「主宇宙中枢 → 独立小世界」二级页面架构
- 每个小世界内含 6 大核心模块：概览、法则、地域、人物、剧情、图库
- 暗色科幻风格视觉体系，带星空粒子动效和毛玻璃卡片
- 响应式设计，同时适配桌面端与移动端
- 3 个原创世界观世界：星落之境、铁锈纪元、翠梦庭阁
